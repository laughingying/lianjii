# 练记 App - 安卓版使用说明

## 一、项目结构

```

├── index.html               # 主应用

```

## 二、两种使用方式

### 方式一：PWA版本（最简单，无需编译）

1. 把 `lianjii-android` 目录上传到任意HTTPS网站
2. 用安卓Chrome浏览器打开网址
3. 点击浏览器菜单 → "添加到主屏幕"
4. 桌面会出现"练记"图标，点击即可全屏运行，体验和原生App一样

**优点**：无需编译、无需上架、更新即时生效
**缺点**：需要HTTPS托管，部分用户不知道怎么添加

### 方式二：编译APK（原生App，可上架应用商店）

#### 准备工作
1. 下载安装 [Android Studio](https://developer.android.com/studio)（免费，Windows/Mac/Linux都支持）
2. 安装时勾选 Android SDK、Android SDK Platform、Android Virtual Device
3. 首次启动会自动下载SDK，等待完成

#### 编译步骤
1. 打开 Android Studio
2. 选择 "Open an existing project"
3. 选择 `lianjii-android-studio` 文件夹
4. 等待 Gradle 同步完成（首次可能需要几分钟下载依赖）
5. 菜单 → Build → Build Bundle(s) / APK(s) → Build APK(s)
6. 编译完成后点击 "locate" 找到 APK 文件
7. APK 路径：`app/build/outputs/apk/debug/app-debug.apk`

#### 生成发布版APK（上架用）
1. 菜单 → Build → Generate Signed Bundle / APK
2. 选择 APK → Next
3. 点击 "Create new..." 创建签名密钥库（.jks文件）
   - 填写密钥库路径、密码
   - 填写别名、密码、有效期（建议25年）
   - 填写姓名、组织等信息
4. 选择 release → Finish
5. 签名后的APK路径：`app/build/outputs/apk/release/app-release.apk`

**重要**：签名密钥库文件(.jks)一定要备份好！丢失后无法更新应用。

## 三、安卓版特色功能

### 1. 物理返回键支持
- 有弹窗时：按返回键关闭弹窗
- 非首页时：按返回键回到首页
- 首页时：按返回键退出App

### 2. 沉浸式全屏
- 隐藏状态栏和导航栏，全屏显示
- 主题切换时状态栏颜色同步变化

### 3. 震动反馈
- 完成训练、解锁奖章时震动提示
- H5可通过 `AndroidBridge.vibrate(50)` 调用

### 4. 数据本地存储
- 所有数据存在手机本地，无需联网
- 支持导出JSON备份、导入恢复

### 上架建议
1. **优先上架**：华为、小米、OPPO、vivo（国内安卓四大厂商，覆盖80%用户）
2. **个人开发者**：小米、OPPO、vivo、荣耀支持个人开发者上架，华为需要企业资质
3. **软件著作权**：应用宝等部分商店需要，可在淘宝/支付宝代办，约300-500元，1-2周下证
4. **隐私政策**：上架需要提供隐私政策页面，可免费生成（如腾讯隐私政策生成器）
5. **应用截图**：需要准备4-5张应用截图（1080x1920）

### 上架材料清单
- 签名后的APK文件
- 应用图标（512x512 PNG）
- 应用截图（4-5张，1080x1920）
- 应用简介（500字以内）
- 隐私政策URL
- 开发者实名认证（身份证+银行卡）
- 软件著作权证书（部分商店需要）

## 五、盈利模式建议

### 一次性买断（推荐）
- 定价：6-12元（健身记录类App主流价格）
- 理由：工具类App用户愿意为无广告、纯离线、数据安全付费
- 对比：时光小铺（时间记录）6元买断，下载量10万+

### 免费+内购解锁
- 基础功能免费（记录、历史）
- 高级功能内购解锁（主题、奖章、数据分析、导出）
- 定价：高级版6-8元

### 注意事项
- 国内应用商店内购需要接入各商店的支付SDK，比较麻烦
- 一次性买断最简单，用户付费下载即可使用全部功能
- 建议先做一次性买断，验证市场后再考虑其他模式

## 六、常见问题

### Q: 编译报错怎么办？
A: 首次编译常见问题：
1. Gradle同步失败：检查网络，可能需要配置代理
2. SDK未安装：点击报错提示的 "Install missing SDK" 自动安装
3. 内存不足：在 `gradle.properties` 中增加 `org.gradle.jvmargs=-Xmx4096m`

### Q: 安装APK提示"未知来源"怎么办？
A: 安卓手机需要在设置中允许安装未知来源应用：
- 设置 → 安全 → 未知来源应用 → 允许
- 或点击安装时按提示跳转到设置开启

### Q: 如何更新App？
A: 
1. 修改 `app/build.gradle` 中的 `versionCode`（+1）和 `versionName`
2. 用同一个签名密钥重新编译发布版APK
3. 上传到应用商店，用户会收到更新提示

### Q: PWA和APK有什么区别？
A:
- PWA：无需编译，添加到主屏幕即可，更新即时，但部分用户不会操作
- APK：原生安装，可上架应用商店，用户获取更方便，但需要编译和签名
